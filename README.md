# CurrencyRate — Приложение «Курсы Валют» 🌍

Проект разработан в рамках курса **Android-разработки от Skillfactory**. Приложение позволяет просматривать актуальные курсы валют, выполнять поиск, добавлять валюты в избранное, просматривать историю, создавать напоминания и настраивать работу приложения.

## 🛠️ Использованный стек технологий

* **Язык разработки:** Kotlin
* **Архитектура:** Single Activity, Fragments, Jetpack Navigation Component
* **Сетевой слой:** Retrofit 2, Gson Converter (API: ExchangeRate-API)
* **Асинхронность:** Kotlin Coroutines, LifecycleScope
* **Локальная база данных:** Room Database (Entity, DAO, AppDatabase)
* **Постраничная загрузка данных:** Paging 3 (PagingSource, PagingDataAdapter)
* **Интерфейс:** ConstraintLayout, RecyclerView, SearchView, BottomNavigationView
* **Настройки приложения:** SharedPreferences
* **Уведомления:** AlarmManager, NotificationManager

---

## 📱 Функционал приложения

### 1. Главный экран

* Отображение актуальных курсов валют.
* Разделение списка на избранные и остальные валюты.
* Поиск валют в режиме реального времени.

### 2. Экран деталей валюты

* Просмотр информации о выбранной валюте.
* Добавление валюты в избранное.
* Создание напоминания о проверке курса.
* Выбор даты и времени отправки уведомления.

### 3. Избранное

* Сохранение выбранных валют.
* Локальное хранение данных с использованием Room Database.

### 4. История

* Автоматическое сохранение просмотренных валют.
* Просмотр истории открытия курсов.

### 5. Напоминания

* Просмотр списка созданных напоминаний.
* Удаление напоминаний.
* Отмена запланированных уведомлений.

### 6. Настройки

* Выбор темы приложения:

    * Системная
    * Светлая
    * Темная
* Выбор стартового экрана приложения.
* Сохранение пользовательских настроек через SharedPreferences.
