# CurrencyRate — Приложение Курсы Валют 🌍

Разработанный проект в рамках курса Android-разработки от **Skillfactory**. Приложение позволяет отслеживать актуальные курсы валют, осуществлять поиск и добавлять выбранные валюты в список избранного.

## 🛠️ Использованный стек технологий

* **Язык разработки:** Kotlin
* **Архитектура:** Single Activity, Fragments, Jetpack Navigation Component
* **Сетевой слой:** Retrofit 2, Gson Converter (API: ExchangeRate-API)
* **Асинхронность:** Kotlin Coroutines, LifecycleScope
* **Локальная база данных (Кэширование):** Room Database (Entity, DAO, AppDatabase)
* **Постраничная загрузка данных:** Paging 3 (PagingSource, PagingDataAdapter)
* **Интерфейс:** ConstraintLayout, RecyclerView (горизонтальная и вертикальная подборки), SearchView для фильтрации, BottomNavigationView

## 📱 Функционал приоожения

1. **Главный экран:** Отображает курсы валют, разделенные на две подборки (избранные/популярные и все остальные).
2. **Поиск:** Реализована фильтрация списка валют в реальном времени с помощью `SearchView`.
3. **Навигация:** Удобное переключение между экранами через нижнюю панель навигации.
4. **Кэширование и Избранное:** Локальное сохранение данных в базу Room. Поддерживается сохранение выбранных валют.
5. **Пагинация:** Постраничный вывод списков с помощью библиотеки Paging 3 для оптимизации ресурсов устройства.
